## Description

Participants learn how user prompts and system prompts differ, then compare how two models interpret a sentence about a nurse and doctor and whether to walk or drive to a car wash. After reading sample instructions, they locate System Prompt in Chat Controls, add the instructions, and regenerate responses to their original prompt. They then try a shared custom model (STEM Adventure Games for teaching, Compare Wikipedia Edits for research), review its system prompt and base model, clone it, revise one instruction, and compare the copy with the original. The session closes with participants drafting instructions using Purpose, Procedure, Constraints, and Format and saving a configuration of their own. The session revises the Spring 2026 workshop of the same name, replacing its disciplinary weak-to-strong examples with one running example that continues through the series.

## Learning Objectives

- Distinguish system prompts, user prompts, and custom models
- Compare two models on the same input and describe the assumptions each makes
- Add in-chat system prompt instructions and regenerate responses without changing the question or settings
- Clone a shared custom model, revise one instruction, and compare it with the original
- Draft a system prompt using Purpose, Procedure, Constraints, and Format, and save a configuration

## Workshop Agenda

### Introductions and Access (0–10 min)

Name, pronouns, role at CUNY, and what brings you to the workshop. Review the access application (CUNY Login, My own access) and Sandbox sign-in. Define system prompts, user prompts, and custom models. Locate the model selector and Compare.

### Compare Model Outputs (10–45 min)

**Who Was Late?** "The nurse yelled at the doctor because she was late. Who was late?" Both models, matching context. Which person does each choose, and on what assumption? Framed through the Winograd Schema Challenge.

**Going to the Car Wash.** "The car wash is 50 meters from me. Should I walk or take the car? Explain your reasoning." What does this person want to accomplish?

**Add System Prompt.** In Controls → System Prompt: "Identify purpose and separate facts from assumptions. Ask one clarifying question when needed. Answer concisely." Regenerate → Try Again on each response. Debrief: what changed, and did either model ask about purpose or explain its assumptions?

### Revise System Prompts (45–75 min)

Try STEM Adventure Games or Compare Wikipedia Edits. Review Base Model and System Prompt; find Purpose, Procedure, Constraints, and Format. Clone in Workspace → Models, rename, revise one instruction, Save & Create. Compare original and copy in one chat. Discuss what changed, whether it worked, and how to test custom models in future work.

### Create Custom Models (75–90 min)

Draft instructions with Purpose, Procedure, Constraints, and Format. Workspace → Models → Create: name, base model, draft prompt, Save & Create, one test request. Keep the draft and choose source documents for Session 2.
