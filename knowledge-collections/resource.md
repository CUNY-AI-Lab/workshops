## Curation Checklist

- ☐ One document, one purpose
- ☐ Metadata and headings in every file
- ☐ A meta document (for example, common-feedback.txt) that signposts how to use the sources
- ☐ Materials for the current unit only; swap as the semester progresses
- ☐ No single giant PDF
- ☐ The system prompt tells the model to draw on the collection
