## Description

This workshop teaches instructors how to build and curate a knowledge collection on the CUNY AI Lab Sandbox: the set of course documents a custom model retrieves from when responding to students. After setting up and testing a model card with the system prompt from Week 1, participants learn what a collection is, where it lives, why it matters, what can be uploaded, and how retrieval-augmented generation chunks and injects passages. Three progressive examples (composition, history, literature) move from a single omnibus file to a three-layer collection. Participants then build a collection for one of their own assignments using copyable templates and test it. This is Week 2 of a 3-week series on using the CAIL Sandbox in the classroom.

## Learning Objectives

- Distinguish the system prompt (behavior) from the knowledge collection (context)
- Describe how retrieval-augmented generation chunks, searches, and injects passages
- Evaluate collections through weak, getting-warmer, and strong examples in three disciplines
- Apply curation best practices and avoid common pitfalls
- Build and test a three-layer collection for one assignment

## Workshop Agenda

### Model Setup

Sign in, open Workspace → Models, create or reopen a model card, name it for the course, select a base model, paste the Week 1 system prompt, save, and test in chat.

### What, Where, Why, Upload

The collection as the reading list for the AI tool. Workspace → Knowledge, attached to the model. Generic midterm advice versus advice grounded in the assignment and the course's SOAPS framework. Twelve document types. Chunking, search, injection, response.

### Part I: What Makes a Good Collection?

1. **Composition & Writing** - 14-page syllabus alone → three-layer collection that grounds revision
2. **Primary Source Analysis** - 42-page textbook chapter alone → collection with SOAPS framework, Reconstruction-era sources with metadata, and reference materials
3. **Close Reading & Literary Analysis** - 180-page course reader alone → collection with New Criticism framework, annotated example, and the current unit's text

### Part II: Best Practices & Pitfalls

One document, one purpose; metadata and headings; supply what's not in the documents; update per unit. Avoid dumping everything in, one giant PDF, forgetting the system prompt, and assuming full coverage.

### Part III: Hands-On Exercise

Layer 1 course framework, Layer 2 assignment materials, Layer 3 source materials, each with a template and a "your turn" prompt.

### Prompt + Collection

An ENGL 101 revision scaffold paired with its collection; test with a question only the collection can answer.
