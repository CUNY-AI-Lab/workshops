## Workshop Categories

- AI Literacy

## Description

A session for the Teaching and Learning Center's Teach@CUNY Summer Institute, designed for faculty with no prior Sandbox familiarity. Participants describe an everyday algorithm, connect that step-by-step logic to how a large language model predicts the next token, and discuss who gets access to AI tools and under what conditions. Two activities on the CUNY AI Lab Sandbox follow: run the same car-wash question in two models and compare what each attended to and assumed, then set a two-sentence system prompt and see how the response changes. Debriefs ask where comparison and system-prompt writing could help students read AI output more critically.

## Learning Objectives

- Connect everyday algorithmic thinking to how a model builds an answer
- Explain at a basic level how a large language model predicts the next token
- Compare the same prompt in two models and describe what each attended to and assumed
- Set a system prompt and compare responses with and without it
- Consider classroom uses of comparison and system-prompt writing

## Workshop Agenda

### Start with an Everyday Algorithm

Icebreaker (conditional, loop, or sequence in three steps) and the bridge to algorithmic thinking: a model builds an answer one step at a time; a prompt is an algorithm you hand it.

### What Is a Large Language Model?

Tokens, vectors, attention, probabilities, output. Discussion prompt on the digital divide.

### Compare Two Model Responses

Sandbox setup, then Activity 1: "The car wash is 50 yards away. Do I walk or do I drive?" in two models. Debrief: notice, missing, teach, try.

### Set One System Prompt

What a system prompt is, then Activity 2: "Read input twice. Do not jump to conclusions." with the same question. Debrief on classroom applications.
