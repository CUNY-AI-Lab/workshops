# AI Literacy Basics

_A CUNY AI Lab session for the Teach@CUNY Summer Institute 2026: from an everyday algorithm to a large language model, a model comparison, and a first system prompt._

This hands-on session introduces faculty to how language models produce answers and gives them two classroom-ready activities on the CUNY AI Lab Sandbox. Participants describe an everyday algorithm, see how that step-by-step logic connects to the way a model predicts text, run one prompt in two models and compare the responses, then set a one-line system prompt and watch how it changes the answer. A discussion prompt on the digital divide and a debrief on classroom uses frame the activities.

## Overview

The session is built for participants with no prior Sandbox familiarity. It reuses the "describe an algorithm" icebreaker from [Creative Coding with Generative AI](../creative-coding/) and bridges it to algorithmic thinking: a model builds an answer one step at a time, and a prompt is an algorithm you hand it. A five-step walk from tokens to vectors to attention to probabilities to output explains what a large language model is. The two activities use the same car-wash question that anchors the Lab's Sandbox workshops, first across two models and then with a two-sentence system prompt, so that participants see both how models differ and how instructions reshape a response.

## Learning Objectives

- Frame an everyday routine as a conditional, loop, or sequence and connect that algorithmic thinking to how a model builds an answer
- Explain, at a basic level, how a large language model turns text into tokens, vectors, weighted context, and a predicted next token
- Run the same prompt in two Sandbox models and describe what each response paid attention to and assumed
- Set a system prompt in the Sandbox controls and compare the response with and without it
- Consider how comparing responses and writing system prompts could help students read AI output more critically

## Workshop Structure

1. **Workshop Agenda** - Start with an everyday algorithm; compare two model responses; set one system prompt; test and discuss
2. **Icebreaker: Describe an Algorithm You Already Know** - A routine in three steps or fewer, framed as a conditional, loop, or sequence
3. **The Bridge: Why Start with an Algorithm?** - Algorithmic thinking demystifies the model and makes prompting clearer
4. **Concept: What Is a Large Language Model?** - Tokens → vectors → attention → probabilities → output
5. **Discussion Prompt: Revisiting the Digital Divide** - Who gets access to AI tools, under what conditions, and how does this shape AI literacy?
6. **Sandbox Setup** - Open chat.ailab.gc.cuny.edu, sign in with a CUNY account, open a new chat, find the model menu and controls
7. **Activity 1: Model Comparison** - "The car wash is 50 yards away. Do I walk or do I drive?" in two models
8. **Activity 1 Debrief** - Notice, missing, teach, try
9. **System Prompts** - Setup instructions for a model: what task, how it operates, what guardrails, what's out of scope
10. **Activity 2: Set a System Prompt** - "Read input twice. Do not jump to conclusions." then the same car-wash question
11. **Activity 2 Debrief** - Comparing responses and writing system prompts as classroom activities
12. **Resources** - CUNY AI Lab sites and workshop code
