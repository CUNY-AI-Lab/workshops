# Vibe Coding How-To

_An operational guide, in slide form, for using command-line coding agents: terminal basics, installing and logging into Gemini CLI, prompt engineering basics, and starting every project with a README._

This short Reveal.js deck distills the setup and working practices from the Lab's vibe-coding workshops into a standalone reference participants can return to. It is listed under Resources on the Lab's links page.

**Format:** Online guide (Reveal.js, authored in Markdown)
**Last updated:** March 2026

## Contents

1. **Command Line Basics** - What the terminal is; opening Terminal (macOS) or PowerShell (Windows); `ls`, `mkdir`, `cd`, `pwd`, `cd ..`
2. **Installing Gemini CLI** - Windows (Node.js, then `npm install -g @google/gemini-cli`) and macOS (Homebrew, then `brew install gemini-cli`)
3. **Login Setup** - Run `gemini`, choose Login with Google; free-tier limits at the time
4. **Prompt Engineering Basics** - Be specific; provide context; iterate
5. **Start with a README** - Ask the agent to write a README first that describes the idea, outlines the structure, and lists features or goals; approve the workflow before building
6. **Resources** - Claude Code, Google AI for Students, GitHub Copilot, GitHub Desktop
