## Description

The first session of the Fall 2026 Vibe Coding Series gives participants a conceptual grounding and a working environment for coding with an AI agent. Part 1 defines vibe coding, explains how a language model generates code one token at a time, shows what turns a model into a coding agent (context, tools, and a feedback loop), and defines context and its limits. Part 2 uses native apps to inspect code, opens the terminal, teaches five navigation commands, distinguishes Git from GitHub, and installs and logs into the GitHub CLI. Part 3 creates a personal CUNY AI Lab API key, explains the shared quota, installs Pi with the Lab's one-command installer, connects it to Lab models, and ends with group troubleshooting. The session revises the Spring 2026 Foundations workshop, replacing Gemini CLI and VS Code with Pi and native tools.

## Learning Objectives

- Define vibe coding, explain how a model generates code, and describe the agent loop
- Explain context and its limits
- Open a terminal and use the five navigation commands
- Distinguish Git from GitHub and log into GitHub with the GitHub CLI
- Create a CUNY AI Lab API key, install Pi, connect it, and run the health check
