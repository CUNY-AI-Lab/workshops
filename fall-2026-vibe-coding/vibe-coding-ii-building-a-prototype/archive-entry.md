## Description

The second session of the Fall 2026 Vibe Coding Series has each participant build and publish a personal website from their own CV with Pi. After setup (API key, Node.js and Git, Pi), participants import the CV as text, choose a design in an on-slide prompt builder, and paste a `/plan` prompt so Pi reads and proposes before editing. They correct the plan, let Pi build plain HTML, CSS, and JavaScript, test the site for factual accuracy, phone-width layout, and console errors, and record the project in `AGENTS.md`. They then customize one change at a time, have Pi create the GitHub repository, commit, and push (checking that the CV file stays private), and enable GitHub Pages. The session revises the Spring 2026 Vibe-Coding Prototypes workshop, replacing Gemini CLI and the focus timer with Pi and a CV site.

## Learning Objectives

- Use `/plan` so the agent reads and proposes before editing
- Build a small site from a structured prompt and verify it
- Write an `AGENTS.md` the agent loads automatically
- Have the agent create, commit, and push a repository, and read what it runs
- Publish with GitHub Pages while keeping private files out

## Workshop Agenda

### Part 0: Review (5 min)

Foundations review.

### Part 1: Setup (25 min)

API key and quota; install Node.js and Git; install and launch Pi.

### Part 2: Plan + Act (35 min)

Set up the project and import the CV; design the site with the prompt builder; planning stage (`/plan`); acting stage; open and test; create `AGENTS.md`.

### Part 3: Prototype + Publish (25 min)

Make it yours; install and authenticate the GitHub CLI; create the remote repository; push; enable GitHub Pages; links and next steps (clinic, coworking sessions, registration).
