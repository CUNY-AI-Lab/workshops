# Co-Developing with Generative AI

_The CUNY AI Lab's first vibe-coding workshop: an introduction to command-line coding agents, with a Site Studio icebreaker, Gemini CLI setup, a README-first build, and a critical debrief._

Participants use a coding agent in the terminal to turn an idea expressed in plain language into a small website, visualization, or script. The session explains how language models produce code and where they fail, gets everyone comfortable with the command line, installs and authenticates Gemini CLI, pauses for critical questions about integrity, bias, environment, labor, and privacy, then runs a hands-on build that starts with a README the agent writes and the participant approves.

## Overview

The deck opens with the day's tools (Site Studio, Terminal or PowerShell, Gemini CLI) and an icebreaker in Site Studio, the Lab's browser-based site builder, where participants share follow-up prompts after a demo. A short conceptual block explains that models predict code from patterns, that command-line agents differ from chat interfaces because they execute commands and read and write files, and that generated code can be plausible but broken, outdated, or insecure. Command-line basics and Gemini CLI installation follow. A "Critical Questions" block covers ethical challenges, power and labor, why use these tools anyway, and when not to. Participants then pick a track (website, visualization, or script), ask the agent to write a README first, build for 15–20 minutes, and reflect on what worked, what didn't, what surprised them, and how they knew the code was correct.

## Learning Objectives

- Explain how language models generate code and name their limitations for coding
- Open a terminal and use basic navigation commands
- Install and authenticate Gemini CLI
- Weigh the ethical, labor, environmental, and privacy questions around AI coding tools and identify when not to use them
- Plan a small project in a README with an agent, build a scoped prototype, and assess the result

## Workshop Structure

1. **Today's Tools** - Site Studio, Terminal/PowerShell, Gemini CLI
2. **Before We Start** - Lab computers or your own; tools installed as we go
3. **Ice Breaker: Site Studio** - Demo, then share follow-up prompts
4. **Understanding Large Language Models** - How LLMs work for coding; limitations; prompt engineering basics
5. **Command Line Basics** - What the terminal is, opening it, essential commands
6. **Installing Gemini CLI** - Windows (npm) and macOS (Homebrew); login with Google
7. **Critical Questions** - Ethical challenges; power and labor; why use AI coding tools; when not to use AI
8. **Choose Your Project Track** - Website, visualization, or program/script
9. **Start with a README** - Describe the idea, outline the structure, list features; approve before building
10. **Hands-On Activity** (15–20 min) - Implement the README's plan with the agent
11. **Let's Reflect** - Discussion of your experience; critical assessment
12. **Resources**
