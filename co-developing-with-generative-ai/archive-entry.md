# Co-Developing with Generative AI - Workshop Archive Entry

## Workshop Overview

**Title:** Co-Developing with Generative AI: Introduction to Command Line Agents
**Date:** Tuesday, November 18, 2025
**Location:** New Media Lab, CUNY Graduate Center
**Format:** Hands-on workshop with a 15–20 minute build
**Facilitators:** Stephen Zweibel, Stefano Morello, and Zach Muhlbauer (CUNY AI Lab)

## Workshop Categories

- AI-Assisted Development
- Developer Tools
- Critical AI Literacy

## Description

The CUNY AI Lab's first vibe-coding workshop. Participants use a coding agent in the terminal to turn an idea expressed in plain language into a small website, visualization, or script. After a Site Studio icebreaker, the session explains how language models generate code and where plausible output fails, teaches command-line basics, installs and authenticates Gemini CLI, and pauses for critical questions about academic integrity, bias, environmental impact, labor, control, and privacy, including when not to use AI. Participants choose a track, have the agent write a README they approve before building, build for 15–20 minutes, and reflect on verification, trust, and appropriate use.

## Learning Objectives

- Explain how language models generate code and name their limitations
- Use basic terminal commands
- Install and authenticate Gemini CLI
- Weigh the critical questions and identify when not to use AI
- Plan in a README, build a scoped prototype, and assess it

## Workshop Agenda

1. Today's Tools; Before We Start
2. Ice Breaker: Site Studio
3. Understanding Large Language Models: how LLMs work for coding, limitations, prompt engineering basics
4. Command Line Basics: the terminal, opening it, essential commands
5. Installing Gemini CLI and login setup
6. Critical Questions: ethical challenges, power and labor, why use AI coding tools, when not to use AI
7. Choose Your Project Track: website, visualization, program/script
8. Start with a README
9. Hands-On Activity (15–20 min)
10. Let's Reflect: your experience; critical assessment
11. Resources
