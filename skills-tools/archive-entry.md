## Description

This workshop completes the Spring 2026 series on using the CUNY AI Lab Sandbox in the classroom. A skill is a structured, plain-text procedure that tells a custom model how to carry out a specific pedagogical move the system prompt cannot cover on its own; a tool is a function the model can call. After a pre-flight check of the system prompt and knowledge collection from previous weeks, participants learn where skills live in Open WebUI, why they matter (a response with and without a stasis-theory skill), what gap they fill, and how tools differ. Three before-and-after examples (establishing stasis, sourcing a document, reading the frame) model a three-part anatomy: trigger, procedure with wait points, format. Participants then write a skill for one move from their own course, add it to their model, and test it.

## Learning Objectives

- Distinguish a skill from a tool and from the system prompt
- Identify a repeatable pedagogical move worth turning into a skill
- Evaluate skills through before-and-after examples in composition, history, and literature
- Write a skill with a trigger, a procedure with wait points, and a format
- Create, attach, reference, and test the skill in the Sandbox

## Workshop Agenda

### Pre-Flight

System prompt and knowledge collection verified; one repeatable pedagogical move named.

### The Basics

What a skill is; activating skills (Workspace → Skills, model card toggle, system prompt reference); why skills matter; the gap skills fill; what a tool is and how to enable tools per chat or per model; skills versus tools.

### Three Examples

1. **Establishing Stasis** (Composition) - one stasis question at a time, tied to the student's words
2. **Sourcing a Document** (History) - quote with metadata, then who, when, for whom
3. **Reading the Frame** (Literature) - description → analysis → interpretation, one formal element per turn

### Writing Your Own Skills

Anatomy: trigger, procedure, format. Choose your move, draft with the template, add to your model, test and iterate.

### What You've Built

System prompt + knowledge collection + skill: three modular layers to test and refine before classroom use.

- Week 1 (March 16): System Prompts
- Week 2 (March 23): Knowledge Collections
- Week 3 (March 30): Skills & Tools
